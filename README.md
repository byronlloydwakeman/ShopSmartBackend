# ShopSmart

## Overview

An idea for an application which can be used to compare the
prices of similar items across British supermarkets.

This is the backend API which scrapes supermarket websites 
to gather data on selected items, which are then returned
via the API to the front-end website.

## Built using:
- Beautiful Soup
- Uvicorn
- FastAPI
- Selenium

Project has been stopped due to similar applications being built
(on mobile), however the scripts can still be used to retrieve
supermarket data for other uses.
